# Gemini Enhancer

A Tampermonkey userscript for Gemini that auto-hides the sidebar.

## Features

- Sidebar auto hides on page load
- Hover over sidebar area to reveal it
- Move mouse away to hide again
- Right border using Gemini's CSS variable `--bard-color-custom-primary-container`

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/)
2. Open `gemini-enhancer.user.js` and click install, or paste the script content into Tampermonkey's editor
3. Visit [Gemini](https://gemini.google.com/)
